How to read this map

Shipped Demo Roadmap

Shipped means it is in the signed 1.0.0 Android build in this repository, with the caveats in the security notes. Demo means the browser page shows an illustration of the function using plain browser storage — it is explicitly not a clinical record and has no encryption, Keystore, sync, reminders, analytics or upload. Roadmap means the function is part of the pattern but needs a server, a clinic, a partner or governance before it can exist honestly; the precondition is named, so it cannot be announced as if it were live. A row can carry two labels where the real function ships and the demo only illustrates it.

The rule across every row: software reads first, a human decides. Nothing in this map diagnoses, prescribes, changes a dose or claims an outcome. Flags and drafts are prompts for a conversation, never instructions.

4. Plan drafting with exposed reasoning

The browser demo illustrates this function inside the Progress → Weekly plan draft section. You can open it directly with the plan-draft deep link. It is a set of review points built only from the days you logged in that browser — never advice, and it does not change any prescription.

FunctionStatusWhat it means hereHonest limit

Exposed reasoning per itemDemoEvery draft point states the evidence — the counts and averages that produced it — under “Why this draft”.Rule-derived and deliberately simple; a clinician can see and reject the basis.

9. Closed-loop medication

The full reference architecture lives in the hospital deployment blueprint, and the workflow is illustrated — with a synthetic cohort and no real records — in the labelled hospital control-room demo. The pattern is described generically; no hospital or named individual is associated with Khai.

What this map is not

A claim of equivalence to any hospital system, a list of clinical results, or a statement that any roadmap item exists today. It is a design map: a way to see which parts of a clinician-supervised digital-health pattern this small project can honestly own, which parts the browser only illustrates, and which parts must wait for a clinic, a server, a partner and governance. The installed app is a measurement instrument; the demo is a marked illustration. Neither is a medical device and neither makes a diagnosis or treatment claim.
