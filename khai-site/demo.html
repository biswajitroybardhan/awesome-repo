Browser demo · no install

The loop, in your browser.

This is the same record shape, the same 83-dish library and the same rules as the Android build — running entirely on this page. Add a plate, mark a medicine, enter a reading, then watch the history fill.

  • One record per day. Food, medicine status, blood pressure, glucose with its context, weight, sleep, mood and a note.
  • 21-day history and progress. A filled square means a record exists. Completeness counts saved days, not good intentions.
  • Five real exports. Metrics CSV, food CSV, a complete JSON backup, an FHIR R4 bundle and a printable one-page clinician summary.
  • English and हिंदी. Switch at any time. Values stay as stable codes, so the record does not change language underneath you.
  • Need data to explore? Settings → sample data fills a realistic fortnight, including missed days.
This is not the Android app.

The demo stores plain objects in this browser’s localStorage. It has no encryption, no Keystore, no sync, no PIN and no reminder. Do not enter real health information here.

The installed app encrypts each day with AES-256-GCM before it is written. That difference is deliberate and it is stated everywhere it matters.
