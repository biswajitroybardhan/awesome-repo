Blocker status

Six release blockers, with what was prepared and what remains
Blocker Status Prepared now Still required
Physical-device testing Not executed tools/device_smoke.ps1 installs the signed APK on an attached device, records model, Android version and signature, collects fatal logcat lines, and prompts for real screen captures. It refuses to run with no device. Connect an Android 7–9 phone and an Android 13+ phone, run the script, complete every row of TESTING.md, and sign §11.
Production keystore / Play App Signing Partially prepared tools/release_key.ps1 generated a dedicated 4096-bit RSA upload key outside the repo, with a random password in a user-only file. A test build signed with it passed 30/30 verification checks. Enrol in Play App Signing in Play Console; back up the upload key; upload the AAB to Internal testing and install through Play. Google holds the app signing key.
Real screenshots Not captured The device script captures five real screens (01-onboarding … 05-guide) into build/device-check/ as a tester navigates. Run it on a real device, review the PNGs, and prepare Play Store listing assets. No screenshots were fabricated.
Live privacy URL Not live khai-site/DEPLOY.md, robots.txt, sitemap.xml and .well-known/security.txt are ready. Publish the static folder over HTTPS and verify all eleven URLs in DEPLOY.md §2 return 200, including https://khaifoods.in/privacy.html.
Monitored mailboxes Not established khai-site/MAILBOXES.md has provisioning, monitoring, escalation and acknowledgement templates. The site honestly says the process is to be established. Create and monitor both addresses, assign two named owners each, and run a delivery and escalation drill before removing the site's placeholder wording.
Native-speaker review of 24 drafts Not reviewed tools/i18n/review_packets.py generated 24 side-by-side packets in docs/review/, each with a sign-off form. All report zero machine-check problems, which is not human approval. Native speakers with clinical and consent competence review and sign each packet; record approval and regenerate the locale resources.
